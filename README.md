# PDF Search Engine

This project allows users to upload PDF files and search text inside them.

## Features
- Upload PDF
- Extract text using OCR
- Search keyword inside PDF
- Simple UI

## Tech Used
- Python (FastAPI)
- HTML + JavaScript
- PyPDF2 / OCR

## How to Run

1. Install requirements
pip install -r requirements.txt

2. Run server
uvicorn main:app --reload

3. Open browser
http://127.0.0.1:8000
